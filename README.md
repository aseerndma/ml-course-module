# ML Course — Module 1

Data exploration of the Titanic dataset using pandas and matplotlib.

## How to run
1. Create and activate a virtual environment
2. Install dependencies: `pip install -r requirements.txt`
3. Run: `python data_exploration.py`
## Outputs
Running the script produces two charts:
- `age_distribution.png` — distribution of passenger ages
- `survival_by_class.png` — survival rate by passenger class
