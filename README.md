# ML Course — Titanic Project

A beginner ML project exploring and predicting Titanic survival.

## Project structure
- `src/` — Python scripts (data exploration, model training)
- `data/` — datasets
- `outputs/` — generated plots and results
- `configs/` — configuration files

## How to run
1. Create and activate a virtual environment
2. Install dependencies: `pip install -r requirements.txt`
3. Explore the data: `python src/data_exploration.py`
4. Train the models: `python src/train_baseline.py`

## Results
Logistic Regression (~80% accuracy) outperformed a Decision Tree,
which overfit the training data.
